Dobro došli u **CSharpAdvanced** repozitorij! Ovaj repozitorij predstavlja izravan nastavak na savladane osnove jezika (`CSharpFundamentals`) i fokusira se na napredne koncepte **C#** programskog jezika i **.NET** platforme, arhitekturu koda, rad s podacima i asinkrono programiranje.

## 📚 Pregled lekcija i koncepata

| # | Mapa / Lekcija | Ključni koncepti | Status |
| :--- | :--- | :--- | :---: |
| **01** | `01_Generics` | Generičke klase, metode i ograničenja (`where T : class`) | ⏳ |
| **02** | `02_Collections` | Napredne kolekcije (`List<T>`, `Dictionary<TKey, TValue>`, `HashSet<T>`, `Queue<T>`, `Stack<T>`) | ⏳ |
| **03** | `03_DelegatesAndEvents` | Delegati, `Func<>`, `Action<>`, `Predicate<>` i događaji (`event`) | ⏳ |
| **04** | `04_LambdaExpressions` | Anonimne metode, lambda izrazi i funkcijski pristup | ⏳ |
| **05** | `05_LINQ` | Upiti nad kolekcijama (`Where`, `Select`, `OrderBy`, `GroupBy`, `FirstOrDefault`, `Any`) | ⏳ |
| **06** | `06_ExtensionMethods` | Proširivanje postojećih tipova bez nasljeđivanja (`this` modifikator) | ⏳ |
| **07** | `07_AsyncAwait` | Asinkrono programiranje (`Task`, `Task<T>`, `async` i `await`) | ⏳ |
| **08** | `08_NullableTypes` | Nullable referentni i vrijednosni tipovi (`?`, `??`, `??=`) | ⏳ |
| **09** | `09_RecordsAndPatternMatching` | Imutabilni modeli (`record`) i napredni `switch` izrazi | ⏳ |
| **10** | `10_Serialization` | Serijalizacija i deserijalizacija podataka (`System.Text.Json`) | ⏳ |
| **11** | `11_ReflectionAndAttributes` | Metapodaci, prilagođeni atributi i inspekcija tipova u runtimeu | ⏳ |
| **12** | `12_MemoryAndDisposal` | Upravljanje resursima, Garbage Collector, `IDisposable` i `using` | ⏳ |

## 🛠️ Korištene tehnologije i alati

* **Jezik:** C#
* **Framework:** .NET SDK
* **Razvojno okruženje (IDE):** JetBrains Rider
* **Verzioniranje:** Git & GitHub

## ⚙️ Kako pokrenuti kod lokalno?

1. **Kloniraj repozitorij:**
   `git clone https://github.com/Carldev04/CSharpAdvanced.git`

2. **Otvori projekt:**
   Pokreni **JetBrains Rider** (ili Visual Studio) i otvori `.sln` / `.slnx` datoteku.

3. **Pokreni odabranu lekciju:**
   Odaberi željeni projekt/lekciju unutar Solutiona i izvrši:
   `dotnet run`
